# Задача определения, перевёрнут ли текстовый кроп с фото

Модель принимает изображение с текстом (цена, телефон, дата, код, слово и т.п.) и выдаёт вероятность того, что оно перевёрнуто вверх ногами

## Идея

- **Данные.** Полностью синтетические: текст рендерится разными шрифтами поверх реалистичных фонов с аугментациями. Учитывается ротационная симметрия символов и строк (по типу `0`, `8`, `Ж`) так как такие примеры не создают сигнала для обучения и размечаются с меткой `0.5`
- **Модель.** Лёгкий CNN-бэкбон из `timm`, затем свёрточная «шея» и схлопывающая признаки голова. Финальный логит это разность скора изображения и скора этого же изображения, повёрнутого на 180°
- **Варианты backbone:** `mobilenetv3_small_100`, `mobilenetv3_large_100`, `resnet18`, `efficientnet_b0`, `mobilevitv2_050`

## Воспроизводимость

Вся генерация данных детерминирована через `numpy.random.default_rng`: `SEED` для обучающих данных, `SEED + 1` — для фиксированной валидационной выборки, чтобы все бэкбоны сравнивались на одних и тех же данных

## Стек

`PyTorch`, `timm`, `OpenCV`
